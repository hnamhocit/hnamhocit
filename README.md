## 👨‍💻 About Me

I'm a Full-stack Developer from Vietnam who enjoys building things from the UI all the way down to the database.

My main experience is around **TypeScript, React/Next.js and Go**, while I also work with **Java, Rust, Flutter and SQL** depending on the problem.

I'm particularly interested in:

* 🧩 Backend architecture & API design
* 🗄️ PostgreSQL, database design & query performance
* ⚡ Building fast and practical applications
* 🛠️ Developer tools and small utilities
* 📱 Cross-platform apps with Flutter
* 🦀 Systems programming & low-level concepts
* 🐳 Docker, Linux & self-hosted infrastructure

> I like understanding **why** something works, not just making it work.
